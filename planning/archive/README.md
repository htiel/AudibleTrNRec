## Interpretation and preservation

- 0.0.1 preserves 29 documents: ten planning documents, twelve original
  reviews/sign-offs, and seven feedback-and-bugs documents. The seven reports
  were uncommitted at transition and moved with the tracked history.
- G0 was a planning PASS; G1 accepted only a narrow private, unofficial
  connector exception. G2–G6 were not passed. Old design sign-offs and private
  implementation GO are not release approvals. See the verdict for the
  controlling implementation assessment.
- Historical statuses, contradictions, estimates, findings, and approvals
  remain as recorded. In particular, older S001 STOPPED / blanket-no-experiment
  text predates the connector amendment; later implementation statements do
  not override the HOLD/FAIL verdict.
- The archive is immutable in substance. The transition repaired only
  relocation-broken links; it did not rewrite findings or retroactively close
  gates. Historical inline code paths and source line numbers describe the
  reviewed revision, not current navigable links. External authority/index
  links still point to the current repository documents, not frozen copies.
- Future corrections belong in dated current-plan change records referencing
  permanent IDs; do not silently edit the archived reports or renumber them.
  A new fix never changes the historical verdict.
